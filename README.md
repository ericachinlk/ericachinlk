## Projects

### [Call Me Maybe](https://github.com/ericachinlk/42-call-me-maybe) · Python
A local LLM function-calling pipeline that turns natural-language prompts into schema-validated JSON function calls using Qwen3-0.6B.
- Constrained decoding with token-level logit masking
- Parameter validation with Pydantic
- ~99% accuracy on the project test set (11 prompts across 5 function types)

### [Codexion](https://github.com/ericachinlk/42-codexion) · C
A multithreaded resource simulation where coder threads compete for shared resources.
- POSIX threads and mutexes protecting shared state
- Deadlock-avoiding resource acquisition
- FIFO and Earliest Deadline First (EDF) scheduling with a custom min-heap priority queue
- Tested with AddressSanitizer and ThreadSanitizer

### [A-maze-ing](https://github.com/ericachinlk/42-a-maze-ing) · Python · team project
A configurable maze generator with a reusable library and command-line interface.
- DFS and Prim's algorithm for generation, BFS for pathfinding
- Compact 4-bit bitmask for cell walls
- Configuration validation and type checking with mypy
